📖 Aide illustrée

Aide rapide : souris et clavier

Sur un point (points visibles)
  • Clic gauche + glisser : déplacer le point
  • Mini-carte (panneau latéral) : vue d'ensemble de la trace, avec le cadre orange de la vue actuelle, une échelle et la flèche du nord
  • Clic droit : supprimer le point
  • Survol prolongé : infobulle (altitude, distance) · case « Infobulles sur les points »
Sur la carte
  • Clic gauche sur une zone vide : ajouter un point (crayon activé)
  • Clic droit : petit menu « Afficher les points » / « Infobulles sur les points »
  • Clic gauche sur le tracé : insérer un point à cet endroit
  • Clic gauche + glisser (zone vide) : déplacer la vue
  • Clic droit + glisser : pivoter / incliner la vue 3D
  • Molette : zoomer / dézoomer
  • Bouton Street View 360° (dans la carte, sous les boutons de zoom) puis clic sur la carte : ouvre Google Street View à cet endroit (Échap pour annuler)
  • Survol du tracé : un rond blanc cerclé d'orange reste accroché à la ligne et la position s'affiche sur le profil altimétrique
  • Clic maintenu (ou doigt) sur le tracé + glisser : le rond suit le tracé sans déplacer la carte
Drapeaux
  • Le premier point est toujours le drapeau vert (départ)
  • Bouton ✓ Terminer (en bas de la carte), touche Entrée ou double-clic sur la carte : marque le dernier point comme arrivée (drapeau à damier)
  • Bouton ↶ (à gauche de ✓ Terminer) ou Échap : annule le dernier point posé
Clavier
  • Échap : annule la sélection en cours, sinon annule le dernier clic (dernier point ajouté)
  • Entrée dans la recherche de lieu vide : recentre la carte sur votre position
Profil altimétrique
  • Survol du profil : le rond de suivi parcourt la trace sur la carte, avec altitude, pente et distance
  • Clic maintenu + glisser : la carte se recentre sur le rond de suivi
Importer un tracé
  • Bouton d'import (en haut à droite) : choisir ou déposer un fichier GPX, CSV ou TXT, ou coller une liste de coordonnées (WGS84, Lambert 72 ou 2008)
  • Puis cliquer sur « Créer/importer la trace ». Pour un GPX, seule la trace est lue (à défaut l'itinéraire, puis les points de passage)
  • Depuis OpenStreetMap : bouton OSM (nuage), onglet « Importer » (mes traces, trace d'un autre utilisateur ou itinéraire balisé)
Cacher les points
  • La case « Cacher les points » masque les points numérotés ; le tracé et les drapeaux départ / arrivée restent visibles
  • Le tracé est alors en lecture seule : ajout, insertion, déplacement et suppression de points, Entrée, Échap, double-clic et saisie de coordonnées sont désactivés
  • Restent disponibles : navigation, profil altimétrique, survol du tracé, export GPX, import, itinéraire suggéré et « Tout effacer »
  • Décochez la case pour reprendre l'édition. Elle n'est disponible que lorsqu'un tracé est présent, et se décoche seule après « Tout effacer »

À quoi ça sert

Dessiner une randonnée sur une carte libre d'accès (fond topographique ou photo aérienne), obtenir sa distance, son dénivelé, son profil altimétrique et ses pentes, puis l'exporter en fichier GPX.

Les icônes en un coup d'œil

  • Importer un fichier GPX, CSV ou TXT, ou une liste de coordonnées.
  • Suggérer un itinéraire (point à point ou boucle).
  • Aide et documentation : cette fenêtre, avec l'aide rapide des gestes en tête (se ferme avec Échap).
  • Exporter : flèche vers le haut, à côté de l'import (à partir de deux points). Menu : télécharger le .GPX, l'envoyer vers un GPS Garmin ou le partager (iPhone, Apple Watch).
  • Google Street View : activer le bouton dans la carte, sous les boutons de zoom, puis cliquer sur la carte ; Street View s'ouvre dans un nouvel onglet, au plus près de l'endroit cliqué. Échap ou un nouveau clic sur le bouton annule.
  • Recherche d'un lieu ou d'une adresse, en haut à gauche de la carte. Entrée sur le champ vide : recentrer sur votre position.
  • Coordonnées du curseur (WGS84, Lambert 72 ou Lambert 2008), en bas à droite de la carte.
  • Réinitialiser l'itinéraire : efface départ, arrivée et passages obligés du panneau d'itinéraire.

Tracer

Au démarrage, une petite fenêtre (déplaçable) propose de tracer à la main ou de suggérer un itinéraire ; sur GSM et tablette, elle propose aussi d'enregistrer son parcours avec le GPS.

  • Créer un point : activez le crayon (en haut à droite), puis cliquez sur la carte. Les points sont numérotés dans l'ordre. Re-cliquer sur le crayon termine (ou reprend) le tracé.
  • Départ : le premier point est marqué d'un drapeau vert.
  • Arrivée : le bouton ✓ Terminer (en bas au centre de la carte pendant le tracé), Entrée ou un double-clic sur la carte marque le dernier point comme arrivée (drapeau à damier rouge). Le bouton ↶ à côté annule le dernier point posé. La barre se déplace en glissant sa poignée ⋮⋮ (double-clic sur la poignée : position d'origine). Sur GSM et tablette, ces boutons remplacent le double-clic et les touches.
  • Boucle : départ et arrivée confondus sont signalés par un drapeau à damier blanc.
  • !Aller-retour : quand le tracé repasse en sens inverse sur la même route ou le même chemin, même sur quelques dizaines de mètres, le tronçon est souligné en jaune pointillé et signalé par un ! rouge (survoler pour la longueur).
  • Déplacer un point : clic gauche maintenu sur le point, puis glisser.
  • Insérer un point : clic sur le tracé, à l'endroit voulu. Supprimer : clic droit sur le point.
  • Annuler : Échap annule la sélection en cours, sinon le dernier point ajouté.

Boutons de tête, réglages et fonds de carte

  • Tout effacer : remet le tracé à zéro (une confirmation est demandée). Icône flèche circulaire, en haut à droite.
  • Vue générale : recadre la carte sur l'ensemble du tracé (disponible dès qu'un point est placé).
  • ✏️Crayon : active le dessin à la main (un clic = un point) ; re-cliquer termine le tracé (le dernier point devient l'arrivée) ou reprend un tracé terminé.
  • ⚙️Réglages (engrenage) : Thème foncé ou clair (calqué sur GPX 3D), Icônes flottantes (les commandes de la carte se déplacent en les faisant glisser ; « Remettre les icônes en place » pour revenir aux positions d'origine), Couleur et Épaisseur de la trace, infobulles et « Cacher les points ». Les choix sont mémorisés.
  • 🗺️Fond de carte (bouton carte, sous Street View) : onglets Général (OpenTopoMap, CartoWeb.be – IGN Belgique), Autres (Plan IGN – France, Geoportail.lu – Luxembourg) et Thème (CyclOSM vélo / VTT, Sentiers balisés – Waymarked Trails, Chasse – SPW Wallonie avec choix de la date) ; superpositions Photo aérienne et Relief 3D.
  • 📋Légende (bouton sous le fond de carte) : symboles de ce qui est affiché — trace, superpositions actives et principaux symboles du fond choisi.
  • •Un petit point orange signale l'outil ou le menu en cours d'utilisation ; ouvrir un outil ferme celui qui était ouvert.
  • Couleur : choisit la couleur de la trace et des points (menu Réglages). Le choix est mémorisé.
  • Photo aérienne (menu Fond de carte) : passe sous le fond choisi. Un curseur translucide apparaît alors en bas de la carte : il règle l'opacité de la carte topographique superposée à la photo, de 0 % (photo seule) à 100 % (carte opaque). Il démarre à 30 %, soit 70 % de transparence ; le survol indique aussi la transparence. Décocher la photo masque le curseur et le remet à 30 %.
  • Relief 3D (menu Fond de carte) : active le relief ; la glissière verticale ou le clic droit + glisser règlent l'inclinaison.
  • Infobulles sur les points (Réglages ou clic droit sur la carte) : altitude et distance au survol prolongé d'un point.
  • Cacher les points (Réglages ou clic droit sur la carte) : masque les points numérotés (drapeaux et tracé restent visibles) et passe le tracé en lecture seule. Disponible seulement quand un tracé est présent.

Importer un tracé

  • Choisir ou déposer un fichier .gpx, .csv ou .txt, ou coller une liste de coordonnées, puis « Créer/importer la trace ».
  • Barre de progression pendant la lecture et la création. Au-delà de 500 points, la trace est simplifiée automatiquement (virages, sommets et cols conservés).
  • Choix des colonnes : si le fichier compte plus de deux champs, on choisit lesquels sont la latitude et la longitude (ou X et Y en Lambert), l'altitude et la vitesse. Une ligne d'en-tête est reconnue et ignorée ; le séparateur (virgule, point-virgule, tabulation, espace) est détecté.
  • Un GPX peut contenir une trace, un itinéraire et des points de passage : seule la trace est lue (à défaut l'itinéraire, puis les points de passage).
  • Si le fichier contient des altitudes, elles sont conservées ; sinon elles sont calculées.

Suggérer un itinéraire

  • Choisir Point à point ou Boucle et l'activité : 🥾 Rando, 🚵 VTT ou 🏍️ Moto.
  • Départ, puis 🏁 Arrivée (point à point) : cliquer chaque point sur la carte. Une étiquette (Départ, Arrivée, Point de passage) suit le curseur pendant le choix.
  • Passages obligés : « + Ajouter » puis clic sur la carte. Les points P1, P2… sont parcourus dans cet ordre ; on les déplace en les faisant glisser et on les supprime par double-clic.
  • En boucle, indiquez la distance souhaitée : elle est approximative, et la boucle cherche à éviter les retours sur le même chemin.
  • Barre de progression pendant le calcul (une boucle teste plusieurs variantes).
  • Réinitialiser le panneau d'itinéraire sans toucher à la trace déjà créée.
  • Rando et VTT utilisent BRouter avec un profil dédié : sentiers et chemins forestiers pour la marche, chemins et single-tracks pour le VTT, routes évitées. La moto utilise un routage routier. Si BRouter est inaccessible, un routage de secours est utilisé.
  • Les allers-retours inutiles (culs-de-sac, pointes) sont supprimés, sauf s'ils sont nécessaires pour atteindre un passage obligé. Le résultat remplace la trace actuelle (confirmation demandée) et reste modifiable point par point.

Aperçu de la trace

  • La mini-carte du panneau latéral montre la trace, avec une échelle et la flèche du nord. Le cadre orange montre la zone affichée sur la grande carte ; si l'on s'éloigne de la trace, la mini-carte s'élargit pour garder ce cadre visible, puis se recadre sur la trace au retour.
  • Un point bleu suit le sommet en cours de déplacement, ou la position survolée sur le profil.

Profil altimétrique et statistiques

  • Les altitudes sont lues dans le modèle numérique de terrain (MNT, tuiles Terrarium AWS), sans limite de requêtes. Un message sous le profil indique la progression.
  • Le panneau latéral donne la distance, le nombre de points, les dénivelés + et −, les altitudes min et max, et la vitesse moyenne si le fichier importé en contient. Le profil et la mini-carte s'adaptent à la taille de la fenêtre.
  • Survoler le profil déplace le rond de suivi le long de la trace sur la carte, avec l'altitude, la pente et la distance. Clic maintenu + glisser : la carte suit le rond. Vide, le profil garde ses axes.
  • Survoler le tracé sur la carte : le rond reste accroché à la ligne et la position s'affiche sur le profil ; clic maintenu (ou doigt) + glisser pour parcourir le tracé sans déplacer la carte.
  • Difficulté (sous les statistiques) : choisir 🥾 Rando ou 🚵 VTT. Rando : Facile, Moyen, Difficile ou Très difficile selon l'effort (km + D+ / 100, méthode suisse), un niveau de plus si la pente dépasse 25 % sur 100 m ; durée selon la norme DIN 33466. VTT : vert, bleu, rouge ou noir selon la distance et le D+, un niveau de plus au-delà de 15 % ; durée sur une base de 15 km/h et 600 m de D+ par heure. Le survol du badge détaille le calcul ; le niveau est écrit dans la description du GPX exporté. C'est une estimation : la technicité du terrain n'est pas connue.
  • Sur une trace très dense, les petites irrégularités du MNT peuvent gonfler légèrement le dénivelé cumulé.

Autres repères sur la carte

  • Le nom du lieu (commune) et la météo affichés en haut sont ceux du point de départ, ou de votre position tant qu'aucun point n'est placé. Survolez le nom pour voir l'adresse complète.

Traces GPS OpenStreetMap

  • Le bouton OSM (nuage) ouvre un panneau à deux onglets, Importer et Envoyer (fermeture par Échap ou clic à côté).
  • Importer › Mes traces : liste vos traces GPS OpenStreetMap ; « Importer » charge la trace choisie dans le panneau d'import, puis « Créer/importer la trace ».
  • Importer › Autre trace : coller le lien ou le numéro d'une trace d'un autre utilisateur. Les traces « publiques » ou « identifiables » sont lues directement (vos traces privées aussi si vous êtes connecté) ; sinon un lien de téléchargement est proposé, puis le fichier obtenu se charge depuis le panneau.
  • Importer › Itinéraire : saisir un nom ou un numéro de balisage (GR 5…) pour chercher les itinéraires balisés de la zone visible, ou coller un numéro de relation, un lien openstreetmap.org/relation/… ou Waymarked Trails. Le champ vide liste les itinéraires de la zone. Variantes et excursions écartées ; altitudes calculées ; plus de 500 points : trace simplifiée en gardant virages, sommets et cols.
  • Envoyer la trace actuelle sur votre compte, avec une description (obligatoire), des étiquettes et la visibilité (identifiable ou traçable). OSM exige un horodatage : des heures fictives à 4 km/h sont ajoutées.
  • Première utilisation : déclarer l'application sur openstreetmap.org (Mes applications OAuth 2, application non confidentielle, droits « traces GPS ») avec l'URI de redirection affichée, puis coller l'ID client. La page doit être ouverte en https:// ou sur http://localhost.

Exporter

  • Le bouton « Exporter » (flèche vers le haut, à partir de deux points) ouvre un menu. Le nom saisi en tête sert de nom de fichier et de nom de trace.
  • Télécharger le .GPX : la trace avec les altitudes connues (Entrée dans le champ Nom fait de même).
  • Vers un GPS Garmin : brancher le GPS en USB, puis choisir le lecteur du GPS ou son dossier Garmin. Le fichier est écrit dans Garmin\NewFiles (montres, Edge, GPSMAP récents) ou, à défaut, Garmin\GPX (eTrex, Oregon…). Éjecter ensuite le GPS proprement : la trace apparaît au redémarrage. Écriture directe sous Chrome ou Edge sur ordinateur ; ailleurs, ou si le GPS n'apparaît pas comme lecteur (nombreuses montres récentes), le fichier est téléchargé et il reste à le copier dans ce dossier.
  • Partager (si le navigateur le permet, notamment sur iPhone) : ouvre le menu de partage avec le fichier GPX. Pour une Apple Watch, choisir une app qui transfère la trace sur la montre, comme WorkOutDoors ; l'app Exercice d'Apple n'importe pas les GPX.
